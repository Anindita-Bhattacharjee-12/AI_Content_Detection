This project implemented two  transformer-based architectures (BERT, DistilBERT) for AI content detection. We implemented a fine-tuning framework using pre-trained models on a text sample of 29146 dataset collected from AI sources and human authors. The BERT based model achieves high performance across multiple epochs with accuracy of 99.50% and strong precision, recall and F1-scores, indicating excellent classification capability. Another model DistilBERT also achieves accuracy of 99.29% at last training epoch. The experimental results show that the proposed models outperform existing detection methods by achieving over 99% accuracy with high precision, recall and F1-scores.
